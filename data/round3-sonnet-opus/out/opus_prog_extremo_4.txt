```python
def collatz_max(nums):
    def pasos(n):
        c = 0
        while n != 1:
            n = n // 2 if n % 2 == 0 else 3 * n + 1
            c += 1
        return c
    return max(nums, key=pasos)
```

Devuelve el número de la lista que tarda más pasos en llegar a 1 con la conjetura de Collatz. Los números deben ser enteros positivos; por ejemplo, `collatz_max([7, 27, 97])` devuelve `27`, que necesita 111 pasos.
