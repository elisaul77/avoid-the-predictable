```python
def kaprekar(n):
    pasos = 0
    while n != 6174:
        d = f"{n:04d}"
        n = int("".join(sorted(d, reverse=True))) - int("".join(sorted(d)))
        pasos += 1
    return pasos

print([kaprekar(x) for x in [3524, 1, 9998, 2111, 6174]])
```

Cualquier número de 4 cifras que no tenga todas las cifras iguales llega siempre a 6174 (la constante de Kaprekar) en 7 pasos o menos. Para eso, cada paso resta el número con las cifras ordenadas de menor a mayor del número con las cifras ordenadas de mayor a menor.
