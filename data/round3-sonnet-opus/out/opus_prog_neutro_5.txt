```python
def kaprekar(n):
    pasos = []
    while n != 6174:
        d = sorted(f"{n:04d}")
        n = int("".join(d[::-1])) - int("".join(d))
        pasos.append(n)
    return pasos

print([len(kaprekar(n)) for n in [3524, 1, 9998, 2026]])  # [3, 5, 5, 6]
```

Cualquier número de 4 cifras que no tenga todas las cifras iguales llega siempre a **6174** (la constante de Kaprekar) en 7 pasos como máximo: se ordenan sus cifras de mayor a menor y de menor a mayor, y se restan.
